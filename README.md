# Project-of-Password-Strength-Validator
## 📌 Description
This project is a simple Password Strength Validator that checks how strong a password is based on different rules like length, numbers, uppercase letters, lowercase letters, and special characters.
## ⚙️ Features
- Check password length
- Detect uppercase letters
- Detect lowercase letters
- Check for numbers
- Check for special characters
- Gives strength level (Weak / Medium / Strong/
## 🧠 How it works
The program evaluates the password and assigns a score depending on the presence of:
- Letters (A-Z, a-z)
- Numbers (0-9)
- Symbols (!@#$%^&*)
Then it displays the strength result.
